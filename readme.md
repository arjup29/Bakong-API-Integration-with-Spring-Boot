## 🛠 How This Software Works

This application uses Spring Boot to create a backend that talks to the Bakong Open API and KHQR SDK.

- Spring Boot manages the commands and controls.

- Bakong Open API allows access to Bakong payment services.

- KHQR SDK formats QR codes according to Cambodia’s standard.

- When you input payment info, it sends that data to Bakong via the API and generates a payment QR code.

- When you input a transaction ID, it queries Bakong to confirm its status.

This process stays hidden. You only interact with simple screens for entering details and scanning QR codes.
